# XMetAI 数据集

## 1. 项目简介

本仓库用于提供 xmetai-core 框架所使用的数据集结构说明与配置方式。
所有数据均采用zarr分块存储，支持按time高效读取。

---

### 2.4 数据集命名规范

数据集名称用于描述数据来源、时间范围、通道数量、空间分辨率、时间间隔及版本信息。例如：

```text
era5.202501_202607.c116.p25.h6.v3
```

| 字段 | 含义 | 示例 |
|---|---|---|
| `era5` | 数据来源 | ERA5 |
| `202501_202607` | 数据覆盖时间范围 | 2025 年 1 月至 2026 年 7 月 |
| `c116` | 通道数量 | 116 个通道 |
| `p25` | 空间分辨率标识 | 0.25° |
| `h6` | 时间间隔标识 | 6 小时 |
| `v3` | 数据集版本 | 第 3 版 |

上述字段的具体含义应以数据集构建配置及实际元数据为准。新增数据集时，应尽量遵循统一的命名规范，避免使用含义不明确的名称。
